## Web の脆弱性

Web アプリケーションを作成するのは、いくつもの乗り越えるべき壁があります。
Webアプリケーションに必要な機能を定義する用件定義、利用者が使いやすいUIとはどう言ったものなのか、
そもそも開発する言語はどうするのか、サーバ側の構成はどうするのか、オンプレミスなのかクラウドを活用するのか。

このようにWebアプリケーションを開発するにおいて、悩みは尽きません。
その中にはWebアプリケーションのセキュリティというものがあります。
安全なWebアプリケーションを作成するにはどうすれば良いのかの答えは、そもそもどう言った脆弱性があるのかを知る必要があります。

Webアプリケーションは、ただ「作って動く」ということが最低限ではなくなり、「作って”安全に”動く」ことが最低限求められることになっています。

脆弱性とは、物事に対して弱点となりうる部分になります。
戦争などにおいても、守るべき地域全てに対して防御を敷くことはできず、どうしても優先順位をつけた上で防御層の濃い、薄いができてしまいます。
その防御が薄い部分が、脆弱なポイントとなり得ます。

このように脆弱性とは、物事に対して脆弱となりうる部分のことを指します。
